# OSINT — Null Origin CTF 2026 (Qualifier)

Open-Source Intelligence challenges: no binaries to break and no code to exploit — just publicly available breadcrumbs (images, handles, business listings, old social-media posts) that you follow to a real-world answer. These three solves are pure investigation: identify the entity, pick the one clue that collapses the search space, and chase it to the artifact that holds the flag.

Each writeup is self-contained and walks through the full investigative chain, with an emphasis on *why* each pivot matters.
